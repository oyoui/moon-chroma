# Changelog

All notable changes to `moon-chroma` will be documented in this file.

## [0.1.0] - 2026-09-27

### Added
- Core `Color` model with RGB boundary clamp protection.
- WCAG 2.1 relative luminance calculation.
- Contrast ratio calculation algorithm (1:1 ~ 21:1).
- Automatic WCAG compliance evaluation (`AAA`, `AA`, `Fail`).
- 6 comprehensive unit tests passing with 100% success rate.
